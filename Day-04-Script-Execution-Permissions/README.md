# Day 04 - Script Execution Permissions

## Objective
Configure executable permissions for Linux shell scripts.

## Commands Used

```bash
chmod 755 /tmp/xfusioncorp.sh
ls -l /tmp/xfusioncorp.sh
```

## Expected Permission

```bash
-rwxr-xr-x
```

## Learning Outcome

Learned Linux file permissions and executable access management using chmod.
