# Day 23: Fork a Git Repository

## Objective
Fork an existing Git repository using the Gitea web interface.

## Repository Details

Original Repository:
sarah/story-blog

Forked Repository:
jon/story-blog

## Steps Performed

1. Logged into Gitea as user `jon`.
2. Opened repository `sarah/story-blog`.
3. Clicked the Fork button.
4. Selected `jon` as the repository owner.
5. Created the fork successfully.
6. Verified the new repository `jon/story-blog`.

## Git Concepts

### Fork
A fork creates a copy of an existing repository under another user's account.

### Benefits of Forking
- Independent development
- Safe experimentation
- Open-source collaboration
- Pull Request workflow

## Outcome

Successfully forked the repository from:

sarah/story-blog

to

jon/story-blog
